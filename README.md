# maoZeDong

> 经典著作选集在线阅读站（HTML + Markdown 双格式逐篇整理）。

## 📌 项目概述

`maoZeDong` 是一套对经典著作选集进行**逐篇整理**的学习资料仓，每篇同时提供 **Markdown** 与渲染后的 **HTML** 两个版本，便于阅读、检索与离线分享。内容按篇章顺序编号组织，覆盖多篇经典著作与知识点系统。

## 🚀 使用

- 阅读：直接打开任意 `.html` 文件
- 复用/分享：使用 `.md` 源文件进行二次整理
