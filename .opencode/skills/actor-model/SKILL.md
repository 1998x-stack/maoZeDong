# 人物的信息世界与组织位置

## 输入
人物列表、`T0`、组织背景及由 `source-research` 建立的来源。先使用 `time-slice`。

## 逐人调查
1. **可证实的位置**：当时职务、是否任命生效、组织链条、与其他机关的指挥协调关系。
2. **权力分解**：提案权、投票权、任免影响、实际执行资源、获得支持的能力；不得由职位名推断全部实际权力。
3. **资料入口**：一手调查、前线电报、会议汇报、党报、国际联络、私人通信；分别记录渠道、送达证据、延迟。
4. **经验模式**：截至 T0 的成功、失败、训练与组织批评，不能用后来的声誉回推。
5. **核心判断**：对局势、机会、失败成本、时间窗口的明确言论；无直接材料则写条件推断。
6. **心理证据**：直接原话 / 行为支持的推测 / 不可验证；不能杜撰对白和隐秘动机。
7. **比较**：相同局势下不同判断的可解释变量是什么；记录仍不可知的因素。

## 严格禁止
使用“天生高明”“必定害怕”等标签替代史料。多年后回忆与同期发言必须分列；同一个人思想随时间变化时建多条有日期的判断记录。
