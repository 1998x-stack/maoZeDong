# 史境 UI Tokens v1

| 类型 | 色值 |
| --- | --- |
| 背景纸张 | `#f6f4ef` |
| 卡片面板 | `#ffffff` |
| 正文墨色 | `#242a2a` |
| 次级文字 | `#69706c` |
| 朱红动作 | `#944541` |
| 证据青绿 | `#48695c` |
| 线框灰色 | `#dedcd4` |

- 中文标题使用 `Songti SC, Noto Serif CJK SC, serif`；正文使用系统无衬线字体。
- 文字区域 max-width 70ch，正文不低于 15px；小字不低于 12px。
- 交互触点至少 44px；必须可键盘操作，`focus-visible` 清晰。
- 不出现过量渐变、历史人物虚构独白、未经确认的历史档案照片。
- 动效仅反馈交互状态；系统启用减少动态效果时取消动画。
- 原文链接和研究报告分别用“去原文”“查看研究稿”明确区分。
