# 文本版本与编订史

## 输入与依赖
一篇具体作品（canonical work ID）和至少两个可检验的文本或出版记录。先加载 `source-research`。

## 工作流程
1. 分清四个层级：写作/讲演 → 最早可考文本 → 后续出版 → 选集编订本。
2. 为每个版本记录 `edition_id`、来源、完成/出版时间、编者、删节依据和是否存疑。
3. 按段落对齐并记录：删节、增补、修辞替换、日期改动、署名变更、编者注释。
4. 对每个差异说明证据能支持的影响；无法证明的作者动机不做结论。
5. 将可能影响当时决策的语句与后来出版后的接受史分开处理。
6. 将站内同一作品多个研究稿挂接到一个 `canonical work ID`，保留旧稿，不直接覆盖。

## 退出条件
仅有网页标题和单一版本时，输出“缺少可核对的版本对照”，不得虚构改动。版权不明时不粘贴大段全文，以定位和简述代替。

## 常见误区
- 网站的“未删节本”标签必须核对来源，不自动等于作者终稿。
- 原著中的注释可能为选集出版时后加，不能在研究 T0 时作为当时观点。
- 同名《实践论》研究报告两篇，不等于存在两个原文不同的《实践论》版本。
