A NOTE ON SOURCES

原著是起点，
不是研究的终点。

本页面仅保存经逐篇定位的目录元数据和原著链接，没有复制外站全文。原文网页可能包含后期选集编者说明；旧 HTML 与 Markdown 是尚未完成研究级审校的解读稿，不代表作者原文。

研究中的人物心理、因果判断和历史反事实需要另外提供同期文献或可靠研究证据。来源冲突、无法获知的情况应如实标记。
