# 原著、史料、版本与转载政策

主要原著索引：https://www.marxists.org/chinese/maozedong/index.htm

## 使用原则
1. 以中文马克思主义文库辨认作品、卷次、文章链接及网站标记的日期。
2. 原著网页、网站编者按、后期选集注释、历史同期文献、当事人回忆和研究论文分别归类；不能互相替代。
3. MIA 在线《毛选》编订版本不自动等于当年的手稿/初刊全文。文稿异同须按版本考证，不靠题目判断。
4. 网站使用条款：https://www.marxists.org/admin/legal/terms-of-use.htm 。在逐篇核实版权之前，仅存文章标题、必要目录元数据、原创摘要和原文外链，不批量复制全文。
5. 不将站内“研究报告”称为“原著”；所有旧稿需史料审阅才可标记 verified。

## 证据责任
- 直接引语给出版本、定位和语境。
- 当时可知与后见信息分开。
- 不从事后成功证明事前必然正确。
- 存在两种互相冲突的版本时保留双边来源和待解决问题。

## 页面责任
“打开原著”是外部链接；“查看研究稿”是仓库已有的历史解读。每个页面用文字说明所处层级。
